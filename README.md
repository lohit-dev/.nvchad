# My NvChad themes

These are the NvChad themes I like and recommend, grouped by how their palettes look. The names in backticks are the theme IDs used by NvChad.

## Soft and muted

- `ashes` — subdued, pastel-like colors on a charcoal background.
- `default-dark` — restrained, familiar editor colors.
- `everforest` — muted greens and warm natural tones.
- `melange` — earthy, low-contrast colors.

## Warm and earthy

- `chocolate` — warm browns with soft accent colors.
- `gruvchad` — retro, autumnal colors.
- `kanagawa-dragon` — dark ink tones with quiet, natural accents.

## Cool and balanced

- **Aylin** (`aylin`) **(daily driver; “ayulin” in my notes)** — cool blue and purple tones.
- `github_dark` — cool gray background with clear blue accents.
- `slatewave` — cool slate colors with a restrained look.
- `tomorrow_night` — classic dark palette with balanced colors.

## Pastel and colorful

- `jabuti` — saturated purple, cyan, and green accents.
- `pastelbeans` — pastel syntax colors on a dark background.
- `espresso` — near-black background with bright, varied accents.
- `vesper` — very dark and minimal, with vivid warm highlights.

To browse or change themes, use `<Space>ft` in Neovim. The selected theme is set in `lua/chadrc.lua`.

---

**This config is built on NvChad.**

- The main nvchad repo (NvChad/NvChad) is used as a plugin by this repo.
- So you just import its modules , like `require "nvchad.options" , require "nvchad.mappings"`
- So you can delete the .git from this repo ( when you clone it locally ) or fork it :)
